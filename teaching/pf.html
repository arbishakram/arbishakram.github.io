CS-2210 Programming Fundamentals

Instructor: Arbish Akram

This course introduces the foundational concepts of programming using C++. Students learn problem solving, algorithm design, and the core constructs of structured programming including variables, control flow, functions, arrays, and pointers. No prior programming experience is required.

Text

  1. C++ How to Program by Paul J. Deitel and Harvey Deitel, 8th Edition
  2. Starting Out with C++ by Tony Gaddis, 8th Edition
